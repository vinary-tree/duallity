# Julia binding

The Julia package is [`Duallity`](Duallity/README.md). It exposes all nine
duallity weighted-transducer adapters as owned `VinaryTreeInterop.Wfst`
objects, so they compose directly with Julia-defined and native lling-llang
graphs.

The [published Julia API guide](https://vinary-tree.github.io/duallity/dev/)
includes an executable dictionary-capture and composition quickstart.
