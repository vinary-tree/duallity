## Citation conventions

- Each entry gives authors, year, title, venue, and a **resolvable identifier** — a
  `https://doi.org/…` link where a DOI exists, an ACL Anthology id for ACL venues, or an ISBN for
  books.
- Inline citations in the prose use bracketed numbers `[[n]]` that resolve within each document's own
  References section; this page is the **consolidated, canonical** list.
- The off-scope bibliography inherited from an earlier project (neural / CFG / text-normalization
  papers) has been retired to [`../roadmap/references/papers.md`](../roadmap/references/papers.md);
  only the works genuinely relevant to duallity appear here.
